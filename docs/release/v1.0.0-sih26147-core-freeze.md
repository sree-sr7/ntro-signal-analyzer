# v1.0.0-sih26147-core-freeze

**Project:** SIH 26147 / NTRO Signal Analyzer  
**Release date:** 2026-10-05

## Freeze purpose

This release records the validated NTRO Signal Analyzer core, production ML
contract, and preserved Tier-2 evidence before a separate GUI UX redesign.
Core behavior and the production model are frozen at this release. GUI UX
redesign happens after this freeze on the `gui-redesign` branch.

## Validation record

  pass; tests were not rerun for this release task).

  `0e0ea216116f8859775b1e55167520db63f95dd93a25a77243bff803ed7fb677`.

- Native Windows GUI manual validation completed by the developer: launch,

## Known limitations

- One of 28,480 randomized CRC-phase hypotheses produced an accepted
  CRC-16 candidate. CRC validation is not a zero-false-accept guarantee.
- T2-04 16-QAM remains unknown/rejected without ground-truth CFO.
- T2-05 has unresolved QPSK phase orientation and is correctly reported as
  partial.
- The controlled oversampled QPSK run was classified as 8PSK and did not pass
  FEC/CRC or recover payload.
- The 0.35 signal-support threshold is bounded fit evidence, not a calibrated
  probability or universal OOD rejection guarantee.
- Inference does not apply the recorded calibration temperature.
- Tier-2 results are a small frozen-capture set; they do not establish
  GNU Radio validation, OTA validation, or general accuracy.
- End-to-end DQPSK, 64-QAM, and 4FSK validation was not established.
